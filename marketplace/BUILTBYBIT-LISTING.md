# BuiltByBit Listing Draft — ECLIPSE Tebex Template

## Title
ECLIPSE - Dark Tebex Store Template

## Summary
A responsive dark Tebex storefront template with editable branding, package pages, custom options, Tebex.js checkout and tiered membership support.

## Category
Websites → Tebex → Templates & themes

## Description
Give your game community a polished storefront with ECLIPSE, a dark, emerald-accented Tebex custom template designed for Minecraft and gaming communities.

### Features
- Responsive desktop and mobile storefront layout.
- Custom homepage with editable hero content, category cards and community section.
- Category and package detail pages.
- Package option form for Tebex custom variables.
- Username login and external login provider page.
- Tebex.js embedded checkout integration.
- Optional tiered membership assets for subscriptions, current tiers, upgrades and pending downgrades.
- No-code Tebex Config Schema for brand text, colour palette, server address, Discord link and homepage display settings.
- Mobile navigation and copy-server-address interaction.
- Static preview included in the download.

### Requirements
- A Tebex store with custom-template access (Tebex Plus or an eligible Tebex Developer Plan).
- Access to Webstore → Appearance.
- Start from the Exo base template and follow the included installation guide.

### Dependencies
- Tebex custom template environment.
- Google Fonts (Space Grotesk and DM Sans) are loaded from Google Fonts when internet access is available; local system-font fallbacks are defined.
- No paid JavaScript or CSS frameworks are required.

### Compatibility Notes
The theme is built for Tebex's Twig custom-template system. Store-specific payment gateways, login providers, package settings, game-server selection, and package delivery remain controlled by Tebex and the store owner. Buyers should test those flows in their own store before publishing.
