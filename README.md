# Universe404 ECLIPSE — Tebex Store Template

A premium dark storefront for Minecraft and gaming communities, built for Tebex's Twig-based custom template system.

## Included

- Webstore page templates: layout, homepage, category, package, checkout and username.
- Responsive CSS with emerald accents and mobile layouts.
- JavaScript enhancements for mobile navigation and copying the server address.
- A Tebex Config Schema for no-code brand, colour and community settings.
- Optional tiered membership and tier-confirmation Twig assets.
- Static preview using sample content only.

## Requirements

A Tebex store with access to custom templates (Tebex Plus or an eligible Tebex Developer Plan), and access to Webstore → Appearance.

## Installation

1. Create a custom template based on Exo in Webstore → Appearance.
2. Replace the matching page files with the files in the Webstore folder. Keep other Exo page files that are not included here so the store retains its other platform flows.
3. Upload eclipse.css and eclipse.js as assets with those exact filenames.
4. If your store uses tiered memberships, upload Assets/category/tiered.html and Assets/quote.html as Twig assets with those paths.
5. Open Change Schema and paste schema.json.
6. Save as draft and test the homepage, a category, a package, username/login, checkout and any tiered memberships you use.
7. Activate only after testing with your own store data.

The preview is static and does not process purchases. A live Tebex store is required to verify final platform rendering and checkout. Never include private tokens or API keys in a theme.
